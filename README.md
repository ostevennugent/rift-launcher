# RIFT

An information-first launcher prototype. Dark glass, live brief, overlays, and assistants that only read what is already on the device.

## Run

```bash
npm install
npm run dev
```

Open the local URL Vite prints. The home screen is Brief. Swipe, or use the Brief / Apps / Deck tabs.

## Use

- Status bar opens controls, including **Ask about this screen**.
- **Ask** on any app sends that screen to Relay, Draft, or Trace.
- Long-press an icon to preview it.
- Settings holds accent, density, pages, modules, overlays, the dock, and the default assistant.

Choices stay in this browser.
